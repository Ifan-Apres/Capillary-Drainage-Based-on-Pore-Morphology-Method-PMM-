# Capillary-Drainage-Based-on-Pore-Morphology-Method-PMM-


This repository contains the source code supporting the Final Year Project titled:
**"CAPILLARY DRAINAGE SIMULATION BASED ON PORE MORPHOLOGY METHOD (PMM) FOR DETERMINATION OF IRREDUCIBLE WATER SATURATION & HYDRAULIC FLOW UNIT"**
By: **Khusnil Arifandi Purnama (NIM: 10222081)**

This project is a Digital Rock Physics (DRP) implementation designed to simulate quasi-static drainage processes using the Pore Morphology Method (PMM) algorithm, accelerated by GPU computation (CUDA). The simulation models the capillary trapping phenomenon to calculate Irreducible Water Saturation ($S_{wirr}$) and capillary pressure ($P_c$) non-destructively, serving as an efficient alternative to conventional laboratory MICP (Mercury Injection Capillary Pressure) testing.

## 📋 Prerequisites

Ensure your system has a Python environment (version 3.8+ is recommended) and an NVIDIA GPU that supports CUDA. The following libraries are required:

```bash
pip install numpy scipy scikit-image matplotlib tifffile porespy pyvista
```

For GPU acceleration, install the `cupy` package that matches your installed CUDA version. For example, for CUDA 11.2:

```bash
pip install cupy-cuda112
```

## 📁 File Structure & Main Modules

This repository consists of three main Python scripts and one configuration file:

1. **`Segmentasi_Laporan.py` (Preprocessing & Segmentation)**
   Loads `.tif` Micro-CT images, applies filtering (Median Filter), contrast enhancement, and binary segmentation using *Otsu Thresholding*. The final output is a binary matrix in `.raw` format (0 = Pore, 1 = Solid) ready for simulation.

2. **`input.txt` (Configuration File)**
   Stores the physical parameters and computational dimensions. This file is read automatically by the simulation script.

3. **`PMM_Cuda112.py` (Main GPU Simulation)**
   The core computational script that implements spatial mathematical morphology (Erosion and Dilation) in parallel on the GPU using CuPy. It calculates phase saturation, detects capillary trapping memory, and computes the capillary pressure versus saturation curve.

4. **`Visualize_Documented.py` (3D Visualization)**
   Reads the drainage history output (.raw files) and renders a 3D visualization of the fluid distribution using PyVista, alongside a 2D Capillary Pressure curve graph.

## 🚀 Workflow Guide

### Step 1: Digital Image Preprocessing

Open `Segmentasi_Laporan.py` and adjust the input file name (`INPUT_TIFF`). You can use the `PREVIEW_ONLY = True` mode to preview the thresholding before executing the full run.

```bash
python Segmentasi_Laporan.py
```

*Output: Visual comparison images (SEM, 3D Sketch) and the `.raw` binary matrix file.*

### Step 2: Physics Parameter Configuration

Open and modify the values inside `input.txt` based on the image resolution and your target fluid conditions.

```text
filename = mtgambier_Segmented_Laporan_khususTA2.raw
filesize_x = 700        # Adjust to the cropped dimensions
filesize_y = 700         
filesize_z = 700         
resolution = 3          # Microns per voxel
sigma = 480             # Interfacial tension (mN/m) (e.g., 480 for Air-Mercury system)
theta = 40              # Contact angle (degrees)
...
```

### Step 3: PMM Simulation Execution

Run the main simulation. Ensure your GPU VRAM is sufficient to load the high-resolution matrix.

```bash
python PMM_Cuda112.py
```

*Output: The script will export the phase history per pressure step into a `Hasil_CUDA_...` folder. Additionally, numerical data will be saved in `result_cuda.txt` (Pc Curve) and `psd_cuda.txt` (Pore Throat Size Distribution / PTSD).*

### Step 4: Visualization

Adjust the input directory in `Visualize_Documented.py` to point to the output folder from the previous simulation step.

```bash
python Visualize_Documented.py
```

*Output: A collection of high-resolution `.png` static images displaying the 3D isometric view of the mercury invasion, XY slices, and the current point on the ongoing drainage curve.*

## 📊 Parameter Extraction & HFU Classification (Advanced)

The numerical data generated by this simulation (`result_cuda.txt`) can be further processed using statistical software (e.g., utilizing Pearson Correlation Matrices and *Agglomerative Hierarchical Clustering*) to extract the Irreducible Water Saturation ($S_{wirr}$), Threshold Pressure ($P_{th}$), and Dominant Radius ($R_{peak}$), as well as to classify the rock into Hydraulic Flow Units (HFU) as detailed in the Thesis document.
